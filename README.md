# Sanjeev-Malladi

By day, I’m a Product Manager. By night, I’m usually found in my home lab, trying to figure out how to make a house "smart" without selling my soul (or my data) to the cloud.

Why does this repo exist? Most people see home automation as a hobby. I see it as the ultimate playground for testing the three things I care about professionally: economics, infrastructure, and scalability. If you’re looking for another profile full of "Hello World" tutorials, this isn't it. This is where I document the actual friction of building a private-first intelligent edge—like trying to get sub-second LLM latency on consumer hardware or figuring out the "Cloud Tax" of a system before I even write the first line of code.

What I’m obsessed with right now:

The Private AI Stack: Moving beyond the API. I’m deep into local orchestration—think RAG, quantization, and edge deployment—because "privacy-first" shouldn't mean "feature-poor."

Systems That Scale (Cheaply): Whether it's a global AWS deployment or a home NVR setup, I’m always looking for the bottleneck. If a system isn't economically viable, it's just a science project.

I hope something here sparks an idea for you. If you’re building something similar, or just want to argue about system architecture, let's talk.
